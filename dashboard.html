จัดการออเดอร์

รับคำสั่งซื้อและเปลี่ยนสถานะ ระบบจะแจ้ง Flex Message ไปยัง LINE ลูกค้าเมื่อสถานะเปลี่ยน

เลขออเดอร์ลูกค้าเวลาประเภทยอดรวมชำระเงินสถานะจัดการ
ไม่พบรายการออเดอร์

เมนูอาหาร

เพิ่ม แก้ไข ราคา รูปภาพ และตัวเลือกเส้นหรือท็อปปิ้ง

ยังไม่มีเมนูอาหาร เพิ่มเมนูแรกของร้านได้เลย

หมวดหมู่อาหาร

จัดกลุ่มเมนูอาหารให้ลูกค้าค้นหาได้ง่าย

ยังไม่มีหมวดหมู่อาหาร

โปรโมชันและคูปอง

สร้างโค้ดส่วนลดแบบจำนวนเงินหรือเปอร์เซ็นต์

โค้ดชื่อโปรโมชันส่วนลดยอดขั้นต่ำใช้แล้วสถานะจัดการ
ยังไม่มีโปรโมชัน

การชำระเงิน

ตรวจสอบสลิปและยืนยันสถานะการชำระเงิน

ออเดอร์ลูกค้าวิธีชำระยอดเงินส่งสลิปเมื่อสถานะสลิป / จัดการ
ไม่พบรายการชำระเงิน

ข้อมูลลูกค้า

ข้อมูลลูกค้าที่เคยสั่งอาหารผ่าน LINE Mini App

ลูกค้าLINE User IDออเดอร์ทั้งหมดยอดซื้อสะสมพบล่าสุด
ยังไม่มีข้อมูลลูกค้า

รายงานยอดขาย

สรุปเฉพาะออเดอร์ที่เสร็จสิ้นแล้ว ยอดขายรายวันและเมนูขายดี

แนวโน้มยอดขาย

ยอดขายรายวันที่ปิดออเดอร์สำเร็จ

เมนูขายดี

เรียงตามจำนวนที่ขายได้
